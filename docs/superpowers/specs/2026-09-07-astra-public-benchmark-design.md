# Astra compatibility and public benchmark

Approved direction: support GPT-6 Astra, record model-specific operational memory, and
publish an independently regradable, complete public benchmark using existing Codex quota.
No paid infrastructure, purchases, or usage-reset redemption is authorized by this plan.

## Product

Resolve the exact public identifier `gpt-6-astra` to `openai/gpt-6-astra`. Keep unknown
models fail-closed and evidence model-specific. Record decisions and outcomes during
operations, not merely in prose at session end. Preserve local-only defaults, privacy
boundaries, signed Commons trust, and all enforcement evidence gates. Never attribute old
unlabelled evidence retroactively to Astra.

## Evaluation

User correction, before scored inference: use SWE-bench Pro directly. HumanEval+ preparation
is retained as unexecuted auxiliary infrastructure, not a substitute for repository evidence.
Run a deterministic prefix of the full 731-task order until the quota reserve or an integrity
gate stops execution; publish exact coverage, never call a prefix a complete benchmark.

Target SWE-bench Pro Public using its official evaluator and pinned dataset and images.
Run identical agent/model/reasoning/prompt/tool/timeout conditions OFF and ON, with
independent task workspaces and memory. Preregister task coverage, configuration, accounting,
failure handling and analysis before inference. Count every task, including failures.
Report quality before token/cost/latency effects and include MARGINAL overhead. Never
claim a partial run is complete, a replay is paired inference, or self-published results
are externally certified. Do not train or tune on scored test outcomes.

First establish real Astra execution and a working evaluator. Preserve at least 20%
of the short quota window for validation/publication. A quota or infrastructure stop is
a documented incomplete run, not a performance result. No promotion of native enforcement
without earned evidence; an explicit experimental intervention is labelled separately.

## Delivery

Publish code, tests, protocol, sanitized machine-readable evidence, analysis and reproduction
instructions on GitHub. Preserve negative findings. Release builds must match source and
the latest upstream signed Commons changes.
